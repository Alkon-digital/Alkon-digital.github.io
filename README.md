# Анамнез — сайт агентства

Статический сайт на [Eleventy](https://www.11ty.dev/). Публикуется на GitHub Pages
автоматически при каждом пуше в `main`.

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:8080 с автообновлением
npm run build    # сборка в _site/
```

## Как устроено

| Путь | Что там |
|---|---|
| `src/_data/site.json` | Общие настройки: название, контакты, меню, **переключатель индексации** |
| `src/_includes/base.njk` | Общий шаблон: шапка, подвал, мета-теги, микроразметка |
| `src/_includes/case.njk` | Шаблон страницы кейса |
| `src/uslugi/`, `src/otrasli/` | Страницы услуг и отраслей |
| `src/keysy/` | Кейсы: один файл — один кейс, индекс собирается сам |
| `src/assets/` | Стили, скрипты, изображения |
| `seo/` | Семантика, разбор конкурентов, выгрузка в Excel |
| `build/icons.mjs` | Пересборка фавиконок из SVG |
| `build/og.html` | Шаблон OG-превью, рендерится через headless Chrome |

## Индексация

Единственный переключатель — `noindex` в `src/_data/site.json`.

- `true` — на всех страницах `<meta name="robots" content="noindex, nofollow">`,
  в `robots.txt` стоит `Disallow: /`. Так сайт живёт, пока идёт разработка.
- `false` — сайт открыт, в `robots.txt` появляется ссылка на карту сайта.

**Переключать на `false` только вместе с переездом на боевой домен.**

## Перед запуском

Незаполненные блоки помечены классом `todo` и видны на странице рамкой.
Проверка, что не осталось ни одного:

```bash
grep -rl 'class="todo"' src/
```

Отдельно удалить перед публикацией: `src/keysy/obrazec-struktura-keysa.md` —
это служебный образец структуры кейса.

## Боевой домен

Сайт переезжает на `anamnez.pro` подключением собственного домена в настройках
Pages. GitHub после этого сам отдаёт 301 с адреса `*.github.io`, поэтому
полноценного переезда с потерей позиций не будет.
